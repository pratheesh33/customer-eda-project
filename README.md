# Customer Behavior Analysis (EDA)

## Project Objective
This project analyzes customer behavior using Exploratory Data Analysis (EDA).

## Dataset Used
Olist Customer Dataset

## Tools Used
- Python
- Pandas
- Matplotlib
- Excel

## Analysis Performed
- Dataset understanding
- Missing value analysis
- Top customer states
- Top customer cities
- Data visualization

## Key Insights
1. SP has the highest number of customers.
2. Customers are concentrated in a few states.
3. Sao Paulo likely has higher market demand.
4. Customer distribution is uneven.
